Language Translation Tool

About the Project

This is a simple web-based language translation tool that allows users to enter text and translate it from one language to another.

The project was created using HTML, CSS and JavaScript. It uses the MyMemory Translation API to provide the translations.

Features

* Translate text between different languages
* Supports English, French, Spanish and German
* Simple and user-friendly interface
* Displays the translated text
* Copy the translated text to the clipboard
* Responsive design for smaller screens

Languages Supported

* English
* French
* Spanish
* German

Technologies Used

* HTML
* CSS
* JavaScript
* MyMemory Translation API

How to Use

1. Enter the text you want to translate.
2. Select the language the text is written in.
3. Select the language you want to translate it to.
4. Click the Translate button.
5. The translated text will appear below.
6. Click Copy Translation to copy the result.
