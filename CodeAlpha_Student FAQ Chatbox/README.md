Student FAQ Chatbox

About the Project

The Student FAQ Chatbox is a simple web-based chatbot designed to answer common questions about a student portal.

The chatbot allows students to type questions and receive answers based on a list of frequently asked questions.

Features

- Answers common student portal questions
- Uses basic Natural Language Processing (NLP)
- Compares the student's question with stored FAQ questions
- Uses cosine similarity to find the closest question
- Simple and user-friendly chat interface
- Works on both desktop and mobile screens

Technologies Used

- HTML
- CSS
- JavaScript
- Basic Natural Language Processing (NLP)
- Cosine Similarity

How It Works

1. The student types a question into the chatbox.
2. The chatbot cleans the question by removing unnecessary words.
3. The important words are compared with the stored FAQ questions.
4. Cosine similarity is used to find the most similar question.
5. The chatbot displays the answer associated with the matching FAQ.

Example Questions

Some questions the chatbot can answer include:

- Where can I see my grades?
- I forgot my password
- How do I register for courses?
