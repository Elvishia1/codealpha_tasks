LSTM Music Generator

Project Description
This project uses a Long Short-Term Memory (LSTM) neural network to generate simple music sequences from MIDI files.

Tools Used
- Python
- Google Colab
- PyTorch
- Mido
- NumPy
- LSTM

How It Works
1. MIDI files were collected from the MAESTRO dataset.
2. Notes were extracted from the MIDI files.
3. The notes were converted into numerical values.
4. Sequences of 50 notes were created for training.
5. An LSTM model was trained to predict the next note.
6. The trained model generated new notes.
7. The generated notes were converted into a MIDI music file.
8. The MIDI file was converted to WAV audio for playback.

Model Structure
- Embedding layer
- LSTM layer
- Fully connected output layer

Training
The model was trained for 3 epochs using the Adam optimizer and Cross Entropy Loss.

Output
The project generated:
- generated_music_piano.mid
- generated_music.wav

The WAV file can be played to hear the music generated by the LSTM model.
